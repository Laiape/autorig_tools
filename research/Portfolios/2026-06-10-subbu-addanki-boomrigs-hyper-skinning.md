# Subbu Addanki — Boom Rigs / Hyper Skinning System

## Perfil profesional
Subbu Addanki es Lead Rigger y Character TD con más de 14 años de experiencia en Animación y VFX, actualmente en Mikros Animation. Sus créditos incluyen Disney (Anaganaga O Dheerudu), Robot/Endhiran (Enthiran — una de las películas indias más caras de la historia), Bilal (largometraje CG completo), Beware The Batman (serie TV), e Ice-Age 4D. Es autor del Hyper Skinning System — un sistema de skinning automatizado para Maya — y de varias herramientas de auto-rig para bípedos, cuadrúpedos, serpientes, pájaros e insectos. Tiene presencia en múltiples plataformas: boomrigs.com, creature-productions.com, subbuadd.blogspot.com, Vimeo, YouTube, SlideShare, tech-artists.org, y animationinsider.com (entrevista).

## Cómo presenta los proyectos
The primary portfolio pieces are the tools themselves, not character credits. Each tool has:
- A descriptive title + the problem it solves
- Technical architecture description (e.g., Hyper Skinning: "disc-and-volume-based mechanism with editable discs, BlendMethod and BlendValue attributes per joint")
- Version history with release notes (v0.4 → v1.0 — shows active development)
- Video demonstrations with the system in action in Maya
- Integration documentation: Hyper Skinning is documented as working in tandem with as_EasyRig (biped), as_EasyQuad (quadruped), as_EasyBird — the tools form an ecosystem

Studio credits appear as secondary context: "Built hyper-real facial setups and auto rigs for bipeds and quadrupeds on Bilal (Full CG feature film)" — production context validates the tools, tools validate the production depth.

The blog documents the development process with the honesty of process: "developed over 2 years using personal time after office hours" — this signals sustained commitment and engineering depth.

## Lo que tiene que Laia no tiene

1. **Narrativa de desarrollo de herramientas con historia temporal.** Addanki no solo describe lo que hacen sus tools — documenta cuándo las construyó, cómo evolucionaron (v0.4 → v1.0), el problema de producción que las motivó, y cuánto tiempo invirtió. Laia tiene 9 tools en pipeline.html con descripciones de una línea. Para Auto Skin Transfer o Skin Manager, una entrada de blog de 300 palabras con "motivación → arquitectura → versión actual → impacto medido" transformaría la herramienta de feature a artefacto de ingeniería.

2. **Documentación del ecosistema de tools como sistema integrado.** Las tools de Addanki se documentan como un sistema: el Hyper Skinning funciona con as_EasyRig, as_EasyQuad, as_EasyBird — se construyó para completar un pipeline, no para resolver un problema aislado. Las 9 tools de Laia están listadas como ítems independientes en pipeline.html sin ninguna documentación de cómo se conectan entre sí en un workflow real. Un diagrama o una frase de flujo ("typical session: Auto Skin Transfer → Skin Manager → IK/FK Match for pose verification") comunicaría sistema vs. colección.

3. **Presencia de plataforma externa por tool.** Cada tool de Addanki tiene un vídeo en YouTube, una entrada en el blog, y un hilo en tech-artists.org. Laia no tiene ningún vídeo ni post externo sobre sus tools — existen solo dentro de pipeline.html, que requiere que el visitante ya esté en su site. Una demo de 3 minutos en YouTube de Auto Skin Transfer es descubrible por cualquier rigger que busque "Maya skin weight transfer tool".
