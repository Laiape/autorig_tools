# Jose Lozano ("Peperig")

## Perfil profesional
Character TD/Rigger desde 2015 (casi 8 años de trayectoria), actualmente/recientemente en Cinesite, con créditos en G20, The Smurfs (2025) e Iwaju. Background técnico centrado en desarrollo de herramientas con Qt/Python/PySide — stack directamente comparable al de Laia (PySide2 UIs).

## Estructura del portfolio
El patrón de título de página ("PepeRig - Portfolio - [Nombre del Proyecto]") confirma que cada proyecto tiene su propia subpágina dedicada, no una home con scroll único. Subpáginas identificadas: `daily_tv.html` (Daily Fables), `ogglies_flm.html` (The Ogglies), `smurfs_flm.html` (The Smurfs), `animalfarm_tv.html`, `turtles_flm.html` (Teenage Mutant Ninja Turtles). Los sufijos de URL (`_tv`, `_flm`) indican una taxonomía deliberada por medio (TV vs. largometraje), separando rutas de navegación según tipo de producción. No hay blog ni página de pipeline/arquitectura unificada — las descripciones de herramientas están integradas en el copy general del site en lugar de vivir en una página dedicada tipo pipeline.html.

## Cómo presenta los proyectos
Cada proyecto tiene su propia subpágina (formato case-study por proyecto, a diferencia del grid único de Laia). La página de The Smurfs incluye contexto de producción inusualmente rico para un portfolio personal: nombra los estudios involucrados ("Paramount Animation, Nickelodeon Animation, LAFIG Belgium and IMPS"), la ventana de estreno ("February 2025"), la guionista ("Pam Brady"), el director ("Chris Miller") y el productor ("Ryan Harris") — se lee como texto de créditos cinematográficos curado, no solo "render + rol".

## Cómo comunica sus skills
Las herramientas se nombran individualmente con una descripción funcional de una línea cada una, no como lista de palabras clave: "a custom shelf built with Python that keeps all custom tools," "a renamer tool to easily rename DCC objects in a visual way," "a tool that allows creating a proxy for layout work from the asset skin," "a tool that keeps all files (modeling, rigging, skin, etc.) in the same folder hierarchy," "a tool that allows editing the visualization of Maya in the outliner by filtering object types," "a tool that allows editing and visualizing all constraints in the scene." Esto es notablemente más específico que una lista o ticker de nombres — cada herramienta tiene un caso de uso/problema declarado en la misma frase.

## Lo que tiene que Laia no tiene
- **Subpáginas de proyecto individuales con créditos de producción nombrados** (estudios, director, guionista, productor, fecha de estreno) incrustados directamente en la página del proyecto — el grid de proyectos de Laia no incluye este nivel de contexto de personal/estudio por proyecto.
- **Cada herramienta de pipeline descrita con una frase de problema/caso de uso explícito** ("renamer tool to easily rename DCC objects," "tool to edit Maya outliner by filtering object types") en lugar de solo el nombre — el pipeline.html de Laia lista las 9 tools solo por nombre, así que esta es una brecha directa y concreta.
- **Taxonomía de navegación por tipo de medio** (sufijos `_tv` vs `_flm` en URLs) que separa explícitamente proyectos de TV vs. largometraje — el proyecto grid de Laia no diferencia tipo de producción.

## Aplicable a Laiape.github.io
1. Para cada una de las 9 standalone tools en pipeline.html, añadir una frase de problema/caso de uso en el mismo formato que Peperig: no "Mesh Data Exporter" sino "Mesh Data Exporter — exporta UVs, vertex colors y skin weights a JSON para preservarlos durante rebuilds de topología." Cambio de menos de una hora con alto impacto en legibilidad técnica.
2. Si alguno de los 7 personajes de pipeline.html corresponde a un proyecto cliente o de estudio real (no solo personal), añadir en esa entrada los nombres de estudio/director/contexto de producción si son públicos — siguiendo el modelo de créditos cinematográficos de la página de Smurfs.
3. Considerar separar el projects grid de Laia por tipo de contexto (personal / cliente / académico) con una etiqueta visual simple, similar a la distinción TV/film de Peperig — ayuda a un recruiter a filtrar rápidamente qué proyectos son de producción real.
