# Sebastien Camrrubi — Senior CG Character TD (Animal Logic / Netflix)


## Perfil profesional
Sébastien Camrrubi es un Senior CG Character TD actualmente en Animal Logic (Netflix, Osaka). Su carrera cubre rigging de personajes para feature animation (Hotel Transylvania 3 en Sony Pictures Imageworks), VFX (Free Guy, WandaVision), games en real-time (Gears 5 en The Coalition/Xbox) y character modeling (Despicable Me 3 en Illumination MacGuff). Para Hotel Transylvania 3 realizó tanto body rigging (Chupacabra, Fishmen, Gremlins) como facial rigging especializado (Macarena Kraken — adaptación facial para secuencia de baile con asset de escala excepcional). Tiene un perfil de ArtStation como portfolio visual principal, Zerply para la industria VFX, IMDb (nm10477122) y un artículo feature en 3DVF. Presencia profesional también en LinkedIn.

## Lo que tiene que Laia no tiene
1. **Separación facial rig / body rig como categorías distintas por personaje**: Camrrubi tiene ArtStation entries separadas cuando hizo facial rigging y body rigging en el MISMO film (Hotel Transylvania 3). Laia lista 7 personajes en pipeline.html sin diferenciar si cada uno tiene facial system, solo body rig, o ambos. Añadir un label de "body rig" / "body + facial rig" / "full system rig" a cada personaje de Laia comunica inmediatamente el alcance técnico de cada uno sin necesidad de texto adicional.
2. **Integración real-time / game engine documentada para al menos un proyecto**: Camrrubi tiene Gears 5 (Maya+Unreal) explícitamente en su portfolio, con el motivo técnico del split ("in-game performance optimization"). Laia no tiene ningún proyecto que documente el comportamiento de sus rigs en un game engine. Incluso una frase — "rig output tested in Unity/Unreal — follows game-export skeleton conventions" — eliminaría este gap para studios AAA.
3. **Nivel de granulado por personaje individual (no por producción)**: Camrrubi tiene al menos 4 entries separadas para Hotel Transylvania 3 (Kraken, Chupacabra, Fishmen, Gremlins) porque son técnicamente distintos. Laia tiene los 7 personajes juntos sin ningún nivel de granulado por tipo o complejidad. Incluso destacar uno o dos personajes con una entry individual más detallada seguiría este patrón.
