# autorig_tools

Autorig modular para Maya 2025+ (Python, rig por matrices, build data-driven
por guias) con notas de export a Unreal.

- Como esta montado y por donde empezar a leer: `como_funciona.md`.
- Como se trabaja en el repo (flujo, reglas, validacion): `CLAUDE.md` y `.claude/rules/`.
- Instalacion: copiar o enlazar `maya_tools/self_module.mod` en la carpeta de
  modulos de Maya y ajustar su ruta absoluta al clone (`maya_tools/como_funciona.md`).
- Licencia: `LICENSE`.
