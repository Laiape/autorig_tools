# Edward fitted garment DQ export

Parent: `maya_tools/how_it_works.md`. Date: 2026-10-16.
Requested delivery: `assets/Edward/skin_clusters/Edward_v072.skc` in the active
nested checkout. Older SKC versions are preserved.

The 23 fitted garment skins from the all-PRX comparison were switched from
Classic Linear to Dual Quaternion (`skinningMethod=1`). Influence lists,
weights and DQ blend weights are unchanged. The two comparison GUI windows had
been closed, so this operation used their saved skin scene in an owned process.
The artist's currently open scene was not modified.

The complete export combines those 23 weights with a fresh native snapshot of
the current artist rig. The other 58 native skin nodes, authored facial layers,
correctives and wrinkle fields keep their current authoring state. The result
has 81 native skin nodes, including 71 serialized polygon-skin records; NURBS
skins remain generated by their existing rig systems. All new garment methods
are DQ. This does not globally change the other authored skin methods.

## Portable model import

Garment records use the original transform paths and canonical `_DQ_SKC` names,
not the temporary comparison-copy names. The 23 original PRX are absent from
the exported graph. Two wrinkle routing records that referred to deleted collar
PRX were retired; fields, masks and surviving consumers were retained.

The fitted copies contain small bind-space offsets relative to the original
model inputs (maximum 0.00470182 cm). The normal SKC geometry payload does not
apply those points when importing onto matching topology. Therefore each garment
stores one static pre-skin `*_BakedBindRest_BLS`, with a constant weight of one,
to preserve its fitted bind shape. These are static offsets with no pose SDK or
per-frame Python. Existing original weights and corrective targets are not
refitted or overwritten.

## Persistence evidence

The SKC uses lossless exact-nonzero float weights. The 23 new skins and their
static rest offsets were removed in the disposable scene and reconstructed by
the production SkinManager importer. A second test also renamed the output
shapes to verify lookup by the canonical model transforms.

Seven poses (neutral, torso, arms, legs, neck, global motion and scale) were
checked forward/reverse: 322 garment comparisons per round-trip test.
Maximum position error was zero, maximum weight error zero, and maximum
face-vertex normal error 6.664e-8. The fixed 1e-4 threshold passed. This confirms
preservation of the new DQ snapshot through SKC import; it does not approve
equivalence to the original proximityWrap deformation.

The file contains wrinkle setup data and no proximityWrap nodes. Publishing used
an exclusive atomic link after the complete JSON was written; the normal active
asset version sequence advanced from v071 to v072.
