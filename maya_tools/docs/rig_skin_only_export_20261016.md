# Edward skin-only garment delivery

Parent: `maya_tools/how_it_works.md`. Date: 2026-10-16.

Requested export: `assets/Edward/skin_clusters/Edward_v073.skc` in the active
nested checkout. This follows v072 and keeps earlier versions intact.

## Requested changes

- Keep the 23 fitted garment skinClusters. Use Classic Linear on `cinturones2`
  and `pCube26`; keep the other 21 fitted garments in Dual Quaternion.
- Remove all 23 experimental static `*_BakedBindRest_BLS` nodes. No shared or
  per-garment pose-target blendshape replacement is included.
- Preserve the nine original blink/corrective blendShapes, authored skin layers,
  existing weights and blend weights, and wrinkle setup.

The source was a fresh native snapshot of the artist's open Edward scene,
including unsaved edits. It already contained 81 skin nodes and no PRX.
Snapshot export preserved the artist scene name and modified state. Export and
persistence checks ran in an owned Maya 2026 process using the active checkout.
After publication, the same requested changes were applied to the artist scene
in one undo chunk. Its existing file was not overwritten.

Removing the static bind offsets intentionally changes neutral points relative
to v072 by up to 0.0047018194 cm (0.0470182 mm). Changing the two skin methods
also intentionally changes their posed output. The persistence check compares
the requested new candidate to its reimport, not to the original PRX.

## Persistence evidence

The lossless SKC contains 71 polygon skin records; native NURBS skin systems
remain generated by the rig. There are no PRX or experimental garment
blendShapes in the serialized deformer graph. Wrinkle setup is present.

All 23 garment weights and blend weights matched before and after preparation.
The native SkinManager importer reconstructed the garment skins after deleting
them and renaming output shapes, using canonical model transform keys.
Seven poses forward/reverse produced 322 comparisons. Maximum position error
was 2.3516582e-5 cm, maximum face-vertex normal error 8.8828227e-5, and maximum
weight error zero. Both geometry limits passed the fixed 1e-4 tolerance.
Native save/reopen matched positions and face-vertex normals exactly across the
seven poses. Both Classic Linear methods persisted.

Two new full CREATE RIG builds and artistic approval of the final build are
not claimed here; the artist requested the export to rebuild and review next.
